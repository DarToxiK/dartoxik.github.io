Privacy policy: claude-google-local

Last updated: 5 November 2026

Who uses this app

claude-google-local is a private tool used only by its owner, on the owner's own Google accounts. It is not offered to the public.

What Google data it accesses

  • Gmail: reads emails and organises them (labels, archive, read/unread, trash). Sending is enabled only on the accounts the owner has chosen.
  • Google Drive: read-only access to files.
  • Google Calendar: reads events and, on accounts the owner has chosen, creates or changes events.

How the data is used

Data is used only to answer the owner's own requests through their AI assistant (Claude, by Anthropic). Content is processed by that assistant to produce the answer. Nothing is used for advertising, profiling or any other purpose.

Storage and sharing

  • Sign-in tokens are stored only on the owner's own computer.
  • No Google data is stored on any server run by this app, because there is none.
  • No data is sold, rented or shared with anyone.

Google API Services User Data Policy

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/connections. Deleting the local sign-in tokens also removes all stored access.
